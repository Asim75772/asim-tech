🔢 Chapter 1: Number System

Numbers help us count, compare and describe quantities. In Class 5, we work with large numbers, place value, comparison and basic operations.

1. Place Value

In a number, the value of a digit depends on its position. For example, in 45,672:

4 = Ten Thousands   |   5 = Thousands   |   6 = Hundreds   |   7 = Tens   |   2 = Ones

2. Expanded Form

We can write a number as the sum of the values of all its digits.

45,672 = 40,000 + 5,000 + 600 + 70 + 2

3. Comparing Numbers

First compare the number of digits. If both have the same number of digits, compare digits from the left.

56,430 > 54,999 because 6 thousands is greater than 4 thousands.

4. Rounding Numbers

To round to the nearest hundred, look at the tens digit. If it is 5 or more, increase the hundreds digit by 1.

3,650 → 3,700 (nearest hundred)

🧮 Solved Examples

Example 1

Write 72,405 in expanded form.

Answer: 70,000 + 2,000 + 400 + 5

Example 2

Which is greater: 68,245 or 68,425?

Answer: 68,425 is greater.

Example 3

Round 8,764 to the nearest hundred.

Answer: 8,800.

Example 4

Add 24,350 + 13,275.

Answer: 37,625.
