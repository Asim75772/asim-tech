📘 সহজে শিখি — ভগ্নাংশের যোগ ও বিয়োগ

1. একই হরের ভগ্নাংশের যোগ

যদি দুই ভগ্নাংশের হর একই হয়, তাহলে লবগুলিকে যোগ করে হরটি একই রাখি।

2/7 + 3/7 = (2+3)/7 = 5/7

2. একই হরের ভগ্নাংশের বিয়োগ

হর একই থাকলে লবগুলির বিয়োগ করি এবং হরটি একই রাখি।

6/9 − 2/9 = (6−2)/9 = 4/9

3. পূর্ণসংখ্যার সঙ্গে ভগ্নাংশ

একটি পূর্ণসংখ্যাকে প্রয়োজন হলে একই হরের ভগ্নাংশে প্রকাশ করে হিসাব করা যায়।

1 + 2/5 = 5/5 + 2/5 = 7/5 = 1 2/5

4. মিশ্র ভগ্নাংশ

মিশ্র ভগ্নাংশে পূর্ণসংখ্যা এবং ভগ্নাংশ—দুই অংশ থাকে। হিসাবের আগে মিশ্র ভগ্নাংশকে অপ্রকৃত ভগ্নাংশে নেওয়া সুবিধাজনক।

1 1/3 + 1/3 = 4/3 + 1/3 = 5/3 = 1 2/3

5. বাস্তব জীবনে ভগ্নাংশ

জলের ট্যাঙ্ক, দুধের বোতল, জমির অংশ, খাবার বা সময়ের বিভিন্ন অংশ বোঝাতে ভগ্নাংশ ব্যবহার করা যায়।

✏️ Solved Examples

Example 1: 2/9 + 4/9
Solution: (2+4)/9 = 6/9 = 2/3
Example 2: 7/10 − 3/10
Solution: 4/10 = 2/5
Example 3: 3/8 + 2/8
Answer: 5/8
Example 4: 1 2/5 + 1/5
Solution: 7/5 + 1/5 = 8/5 = 1 3/5
Example 5: একটি চৌবাচ্চার 7/8 অংশ জলভরা ছিল। 2/8 অংশ জল ব্যবহার করা হলো। কত অংশ জল রইল?
Solution: 7/8 − 2/8 = 5/8
Example 6: 3/6 + 2/6 = ?
Solution: 5/6 = 5/6
