16. নিয়ন্ত্রিত সংখ্যা ও সংখ্যারেখা সম্পর্কিত ধারণা

Class 6 Mathematics • Notes • Examples • Practice • MCQ Test

Notes

নিয়ন্ত্রিত সংখ্যা

সংখ্যারেখায় 0-এর ডানদিকে ধনাত্মক এবং বামদিকে ঋণাত্মক সংখ্যা থাকে।

... -3, -2, -1, 0, 1, 2, 3 ...

সংখ্যারেখা

ডানদিকে গেলে সংখ্যা বাড়ে, বামদিকে গেলে সংখ্যা কমে।

বিপরীত সংখ্যা

5-এর বিপরীত -5 এবং -5-এর বিপরীত 5।

Examples

Example 1: 3 + (-5) = -2।
Example 2: -2 + 6 = 4।
Example 3: 4 - 7 = -3।
Example 4: -3 - 2 = -5।

Practice
