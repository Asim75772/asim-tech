📘 Notes

1. What is a Fraction?

A fraction represents a part of a whole. In 3/5, 3 is the numerator and 5 is the denominator.

Fraction = Numerator ÷ Denominator

2. Types of Fractions

  • Proper fraction: numerator is smaller than denominator, e.g. 3/7.
  • Improper fraction: numerator is equal to or greater than denominator, e.g. 9/4.
  • Mixed fraction: whole number with a proper fraction, e.g. 2 1/4.

3. Equivalent Fractions

Fractions that have the same value are called equivalent fractions.

1/2 = 2/4 = 3/6 = 4/8

4. Comparing Fractions

For fractions with the same denominator, the fraction with the larger numerator is greater.

Example: 5/8 > 3/8.

5. Adding and Subtracting Like Fractions

2/7 + 3/7 = 5/7
6/9 − 2/9 = 4/9

6. Decimals

Decimals are another way of representing parts of a whole. For example, 0.5 = 5/10 = 1/2.

  • Tenths: 0.1
  • Hundredths: 0.01
  • Thousandths: 0.001

7. Comparing Decimals

Write the decimals with the same number of decimal places and compare from left to right.

0.70 > 0.65

8. Adding Decimals

Always keep the decimal points aligned.

2.35 + 1.40 = 3.75

Answer: (2×3+1)/3 = 7/3.
