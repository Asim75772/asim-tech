🔢 Chapter 1: Number System

Numbers are used to count, compare and describe quantities. In this chapter we learn place value, face value, expanded form, comparison, ordering, rounding and basic operations with large numbers.

1. Place Value & Face Value

Face value is the digit itself. Place value is the value of the digit according to its position.

45,672
4 → Ten Thousands = 40,000
5 → Thousands = 5,000
6 → Hundreds = 600
7 → Tens = 70
2 → Ones = 2

2. Expanded Form

Expanded form writes a number as the sum of the place values of its digits.

45,672 = 40,000 + 5,000 + 600 + 70 + 2

3. Standard Form

When the expanded values are added together, we get the standard form.

30,000 + 4,000 + 500 + 20 + 8 = 34,528

4. Comparing Numbers

First compare the number of digits. If both numbers have the same number of digits, compare from the leftmost digit.

68,425 > 68,245 because at the hundreds place, 4 is greater than 2.

5. Ascending & Descending Order

Ascending: smallest to largest.   Descending: largest to smallest.

Ascending: 2,450, 3,200, 4,125, 5,010
Descending: 5,010, 4,125, 3,200, 2,450

6. Rounding Numbers

To round to the nearest hundred, look at the tens digit. If it is 5 or more, increase the hundreds digit by 1. If it is less than 5, keep the hundreds digit unchanged.

3,650 → 3,700 (nearest hundred)
3,624 → 3,600 (nearest hundred)

7. Addition & Subtraction

Always align the digits according to their place values before adding or subtracting.

24,350 + 13,275 = 37,625
50,000 − 18,750 = 31,250
💡 Study Tip: Read the place-value table aloud and practise writing large numbers in both standard and expanded form.

🧮 Solved Examples

Example 1

Write 72,405 in expanded form.

Answer: 70,000 + 2,000 + 400 + 5

Example 2

Find the face value and place value of 8 in 58,214.

Answer: Face value = 8; Place value = 8,000.

Example 3

Arrange 45,678; 45,768; 44,999 in ascending order.

Answer: 44,999 < 45,678 < 45,768.

Example 4

Round 8,764 to the nearest hundred.

Answer: 8,800.

Example 5

Add 24,350 + 13,275.

Answer: 37,625.

Example 6

Subtract 18,750 from 50,000.

Answer: 31,250.
