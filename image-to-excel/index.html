ℹ️ How to use

1. Camera অথবা Choose File দিয়ে table-এর ছবি নিন।

2. বাংলা + English থাকলে OCR Language → বাংলা + English নির্বাচন করুন।

3. যদি 3 column-এর table হয় → 3 Columns দিন।

4. যদি 7 column-এর table হয় → 7 Columns দিন।

5. Extract Table চাপুন।

6. OCR result-এর cell-এ tap করে ভুল ঠিক করুন।

7. Download Excel চাপুন।
