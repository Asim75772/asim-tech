ℹ️ How to use

1. Tap Choose Image and select a photo from your phone.

2. Select English, বাংলা or বাংলা + English.

3. If you know the number of columns, select it. For example, a 3-column table → select 3 Columns.

4. Tap Extract Table.

5. Correct OCR mistakes by tapping cells.

6. Tap Download Excel.
