ℹ️ How to use

1. Tap Choose Image and select a photo.

2. Select English, বাংলা or English + বাংলা.

3. For a 3-column table, select 3 Columns.

4. Tap Extract Table.

5. Correct OCR mistakes in the cells.

6. Tap Download Excel.
