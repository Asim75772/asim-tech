ℹ️ How to use

1. Tap Choose Image.

2. Select a photo/screenshot from Gallery or Files.

3. Select OCR language.

4. Select the expected number of columns, or leave it as Auto Detect.

5. Tap Extract Table.

6. Correct any OCR mistakes directly inside the table.

7. Tap Download Excel.
