📷 Image to Excel

📄

Upload List / Table Image

Camera দিয়ে ছবি তুলুন অথবা Gallery থেকে image select করুন। বাংলা ও English দুটোই ব্যবহার করা যাবে।

Preparing OCR...

📊 Extracted Table

প্রতিটি cell-এ click করে OCR ভুল ঠিক করতে পারবেন। তারপর Download Excel করুন।

ℹ️ How to use

1. Choose Image / Camera চাপুন।

2. English, বাংলা অথবা বাংলা + English select করুন।

3. ছবিতে যতটি column আছে সেটি select করুন।

4. Extract Table চাপুন।

5. প্রয়োজনে cell-এর OCR লেখা ঠিক করুন।

6. Download Excel চাপুন।
